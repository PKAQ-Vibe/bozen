# data/ 种子数据

> v1 无后端：本目录的 JSON 仅作为构建期种子数据。运行时状态（积分、任务完成情况、时间银行、兑换记录）使用 AES-256-GCM 加密后写入浏览器 IndexedDB。
> 迁移到 ant design pro 时，请把 `src/services/` 内部 `loadSeed*()` / `persist*()` 实现替换为 HTTP 请求即可，模型与页面层无需改动。

## 文件清单

| 文件             | 说明                                                   |
| ---------------- | ------------------------------------------------------ |
| `subjects.json`  | 学科基本信息（id / 中文名 / 配色 / emoji）              |
| `tasks.json`     | 任务模板（不带日期，运行时按日生成实例）                |
| `shop.json`      | 奖励商城商品（三大类：game / privilege / football）     |
| `config.json`    | 激励参数（番茄钟/时间银行/挑战通道，统一调参入口）      |

## 注意

- 修改种子后，可在家长端“数据备份”页面刷新今日任务或清空加密数据，使新模板完整生效。
- `standardMinutes` 在 v1 直接来自种子，不暴露给孩子修改；后续家长端实现「动态校准」时，落点在这个字段。
